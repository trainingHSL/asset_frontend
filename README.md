# IT Asset Management System - Frontend

React + Vite frontend for the IT Asset Management System.

## Setup

```bash
cd asset_frontend-main
npm install
copy .env.example .env
npm run dev
```

`.env`:

```env
VITE_API_URL=http://localhost:5000/api
```

Open:

```txt
http://localhost:5173
```

The login screen now includes a **Create Organization** option, so you can create the first organization without Postman.
